# 実践プレイブック — 出力をどう動画制作に活かすか

ツールが出したスコアを、実際の投稿判断にどう落とすかの指針です。

---

## 毎日のルーティン (5 分)

```bash
ttradar run
open reports/latest.html
```

見る順番:

1. **🚀 伸び始め の商品** — 最優先。今日撮って今日出す
2. **🚀📈 のハッシュタグ** — 動画に乗せるタグを決める
3. **🚀📈 の楽曲** — BGM を決める
4. **⚠️📉 のもの** — **作らない判断**をするために見る

最後の 4 番目が意外と重要です。
「今ちょうど流行ってる気がする」ものが実はピークアウト済み、というのはよくあります。

---

## 商品の選び方

スコア上位から、以下を確認してください。

### ✅ 作るべき商品の条件

| 条件 | 目安 | 理由 |
|---|---|---|
| ステージ | 🚀 伸び始め / 📈 上昇中 | ピーク以降は公開時に遅い |
| 競合動画数 | **3 桁未満** | 100 本超えているなら先行者利益は薄い |
| 報酬率 | 15% 以上 | 10% 未満は労力に見合わない |
| 価格 | 1,000〜6,000 円 | 衝動買いされる帯。高額は購入ハードルが高い |
| レビュー評価 | 4.0 以上 | 低評価品の紹介はフォロワーの信頼を失う |
| 自分で使えるか | — | **使ったことのない商品は撮らない** |

### ❌ 避けるべきもの

- **⚠️ ピーク / 📉 下降** — 撮影・編集・公開のリードタイムを考えると確実に遅い
- **競合動画が 4 桁** — 同じ商品の動画が 1,000 本ある中で勝つのは難しい
- **評価 4.0 未満** — 短期の再生数より、返品・クレームでアカウントの信頼が落ちる方が痛い
- **高額商品 (1 万円超)** — 再生数が出ても購入に繋がりにくい

### 「競合が少ない」の使い方

これがこのツールで一番価値のある数字です。

```
スマホ冷却クーラー   スコア 67   紹介動画がまだ 19 本 (先行者になれる)
シートマスク 30枚    スコア 30   紹介動画が 1,388 本と飽和気味
```

後者は販売数では圧勝していますが、**あなたが作る 1,389 本目の動画**に
アルゴリズムが回してくれる理由はありません。
前者の 20 本目になる方が期待値が高いです。

## ハッシュタグの使い方

`#購入品紹介` のような 100 万投稿クラスの巨大タグだけを付けても埋もれます。
**大・中・小を混ぜる**のが定石です。

| 規模 | 役割 | ttradar での見方 |
|---|---|---|
| 大 (数十万〜) | ジャンル認識 | 「現在値」が大きいもの |
| **中 (数千〜数万)** | **実際に効く** | **🚀📈 かつ競合が少ないもの** |
| 小 / ニッチ | 刺さる層に届く | 商品名・具体的な悩みワード |

ttradar が 🚀 を付けた中規模タグが、狙うべきゾーンです。

---

## 楽曲の使い方

- 🚀 伸び始め の楽曲は、**同じ曲を使う動画がまだ少ない**うちに乗る
- ただし商品紹介動画では**音声解説が主役**なので、BGM は音量を下げて使う
- 楽曲トレンドは寿命が短い (1〜2 週間) ので、ハッシュタグより鮮度が重要

## 競合の定点観測

全体トレンドより、**自分と同じニッチで伸びている人**を見る方が学びが早いです。

```bash
ttradar watch add creator @competitor1 --note "美容家電ジャンル"
ttradar watch add creator @competitor2
```

`sources` に `ytdlp_watch` を追加して定期実行すると、
その人の直近動画の再生数が時系列で記録されます。

見るポイント:

- **どの動画だけが突出して伸びたか** — 平均の 5 倍伸びた動画には理由がある
- **最初の 3 秒 (フック)** — 何を見せて離脱を止めているか
- **投稿頻度と時間帯**
- **伸びた動画の商品ジャンル**

伸びた 1 本を見つけたら、**その構成を自分の商品で再現する**のが最短です。

## 設定のカスタマイズ

### 自分のニッチを登録する

```yaml
my_niches: [美容, コスメ, 時短, キッチン]
```

合致するものが 15% 加点されます。
全ジャンルの 1 位より、**自分が明日撮れるジャンルの 3 位**の方が価値があります。

### 「新しさ」重視に振る

早期発見を最優先にするなら:

```yaml
weights:
  growth: 0.30
  acceleration: 0.35      # 加速度を最重視
  volume: 0.05            # 絶対数は軽視
  freshness: 0.15
  competition: 0.15
```

### 「確実性」重視に振る

ある程度実績のあるものを堅く狙うなら:

```yaml
weights:
  growth: 0.35
  acceleration: 0.15
  volume: 0.30            # ボリュームを重視
  freshness: 0.05
  competition: 0.15
```

### 商品の価格帯を変える

高単価ジャンル (家電など) を扱うなら:

```yaml
price_sweet_spot: [5000, 30000]
```

## よくある失敗

| 失敗 | なぜ起きるか | 対策 |
|---|---|---|
| 1 回だけ実行して「伸び率が出ない」 | 差分が無いと計算できない | 2〜3 日、1 日 2 回実行して貯める |
| スコア 1 位を機械的に選ぶ | 自分が使えない商品でも 1 位になる | **根拠の列を読む**。使ったことのない商品は撮らない |
| 巨大トレンドにだけ乗る | 競合が多すぎる | 競合数を見る。3 桁未満を狙う |
| 通知が多すぎて見なくなる | 閾値が低い | `alert_threshold` を 80 に上げる |
| 通知が来ない | 閾値が高い / 履歴不足 | `alert_threshold` を 60 に下げる。まず履歴を貯める |

---

## 最後に

このツールは**候補を絞る**ためのものです。
最終判断は「自分がその商品を良いと思えるか」「自分のフォロワーに合うか」です。

スコア 90 の商品でも、使ったことがなければ紹介動画の説得力は出ません。
**スコアは順番を決めるもので、答えではありません。**
